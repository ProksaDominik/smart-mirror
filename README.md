**Project Summary in max 10 words:** 
SmartMirror – Morning Assistant

SmartMirror is an AI-powered smart mirror built on a Raspberry Pi that helps people start their day faster without reaching for their phone. It uses a YOLO-based face recognition model to identify who is standing in front of the mirror from a set of 6 registered users. Once recognised, the mirror automatically fetches that person's personalised data from Google Cloud. It displays the current time, live weather forecast, and a synced to-do list pulled from Google Calendar on a 10.1-inch HDMI touch LCD. An LED strip lights up green on successful recognition and red on failure, while a speaker plays a personalised greeting. A physical button lets the user trigger or restart the recognition cycle without any keyboard or mouse. The wooden enclosure features a laser-cut frame with an acrylic one-way mirror, hidden cabling, and LED accents for a clean smart-home look. Users manage their calendar and tasks entirely from their phone via Google Calendar, which syncs automatically to the mirror. A Gradio web interface provides four pages: About, Data, Operating, and Debugging for full remote control and diagnostics. The goal is to save 10–15 minutes every morning by delivering all essential daily info at a glance, hands-free.
